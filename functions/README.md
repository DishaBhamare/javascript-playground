# Functions 

## Concepts Covered 
- Function declarations 
- Calling functions 
- Parameters and arguments 
- Return values 
- Local variables 
- Global variables 
- Default parameters 
- Function expressions 
- Arrow functions 
- Function scope 

## Key Takeaways 
- Functions help reuse code. 
- Parameters receive input values. 
- return sends a value back. 
- Local variables exist only inside the function. 
- Global variables can be accessed throughout the program. 
- Arrow functions provide shorter syntax. ## Common Mistakes 
- Forgetting to call the function. 
- Expecting access to local variables outside the function. 
- Forgetting to use return when a value is needed.
