# Error Handling (try...catch)

## Overview 

Error handling allows JavaScript programs to deal with unexpected situations without crashing.

 ## Concepts Covered 
 - try 
 - catch 
 - finally 
 - throw 
 - Error object 
 - Runtime errors 
 
 ## Key Takeaways 
 - Code inside `try` executes normally. 
 - If an error occurs, control moves to `catch`. 
 - `finally` always executes. 
 - `throw` is used to create custom errors. 
 - The `Error` object contains useful information such as `name` and `message`. 
 
 ## Real-World Uses 
 - API calls - Form validation 
 - File handling - Database operations 
 - Network requests
