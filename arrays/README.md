## Key Takeaways

- Array indexes start from `0`.
- `length` gives the number of elements.
- `map()` creates a new array by transforming elements.
- `filter()` creates a new array containing matching elements.
- `reduce()` reduces an array to a single value.
- `find()` returns the first matching element.
- `forEach()` is used to perform an action for every element.
- `slice()` does not modify the original array.
- `splice()` modifies the original array.
- `sort()` sorts values as strings by default.
- `Array.isArray()` checks whether a value is an array.
- The spread operator can be used to copy or combine arrays.
