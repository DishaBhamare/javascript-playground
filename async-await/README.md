# Async / Await 

## Concepts Covered 
- async functions 
- await keyword 
- Returning promises 
- Error handling 
- Multiple awaits 
- Promise.all 
- Sequential vs parallel execution 
- Common mistakes 

## Key Takeaways 
- `async` makes a function return a promise. 
- `await` pauses only the async function, not the entire program. 
- Use `try...catch` for rejected promises. 
- Use `Promise.all()` for independent tasks. 

## Real-World Uses 
- API requests 
- Authentication 
- Database queries 
- File operations 
- Multiple network calls
