# Variables 

## Concepts Covered 
- Creating variables 
- Updating variables 
- Naming rules 
- let 
- const 
- var (legacy) 
- const with objects 

## Key Takeaways 
- `let` is used for values that may change. 
- `const` is used for values that should not be reassigned. 
- Variable names are case-sensitive. 
- `var` is legacy syntax and is generally avoided in modern JavaScript. 

## Real-World Uses 
- User input 
- Counters 
- API data 
- Configuration values 
- Application state
