# Callbacks

## Concepts Covered

- Callback functions
- Passing functions as arguments
- Anonymous callbacks
- setTimeout
- Event loop basics
- Nested callbacks
- Callback hell

## Key Takeaways

- Functions are first-class citizens in JavaScript.
- A callback is passed, not executed immediately.
- Callbacks are commonly used in asynchronous programming.
- Excessive nesting leads to callback hell.
- Promises and async/await provide cleaner alternatives.
