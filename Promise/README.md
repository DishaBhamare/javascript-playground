# Promises 

## Concepts Covered 
- Promise basics 
- Pending / Fulfilled / Rejected 
- resolve() - reject() 
- .then() 
- .catch() 
- .finally() 
- Promise chaining 
- Error propagation in chains

## Key Takeaways 
- Promises represent future values. 
- `.then()` handles success. 
- `.catch()` handles failure. 
- `.finally()` handles cleanup. 
- Promises help avoid callback hell. 

## Real-World Uses 
- API requests 
- Database operations 
- File uploads 
- Authentication 
- Timers and asynchronous tasks
